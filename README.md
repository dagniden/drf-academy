## Контекст проекта

В мире развивается тренд на онлайн-обучение. Для веб-разработчика важно не только обучиться, но и знать, как реализовать платформу для онлайн-обучения.

Данный проект представляет собой разработку **LMS-системы** (Learning Management System), в которой каждый желающий может размещать свои полезные материалы или курсы.

Результатом создания проекта будет **бэкенд-сервер** на Django REST Framework, который возвращает клиенту JSON-структуры для SPA веб-приложения.

## Задание 2: Модели данных

### Модель `User` (приложение `users`)

**Пользователь** с кастомной аутентификацией:
- Все поля от обычного пользователя Django
- **Авторизация по email** (вместо username)
- Телефон
- Город
- Аватарка

### Модели `Course` и `Lesson` (приложение `academy`)

**Курс:**
- Название
- Превью (картинка)
- Описание

**Урок:**
- Название
- Описание
- Превью (картинка)
- Ссылка на видео

> **Связь:** Урок и курс - это связанные сущности. Уроки складываются в курс, в одном курсе может быть много уроков (связь `ForeignKey`).

## Задание 3: CRUD операции

### Курс (ViewSets)
Реализуйте CRUD для модели `Course` с использованием **ViewSets**.

### Урок (Generic-классы)
Реализуйте CRUD для модели `Lesson` с использованием **Generic-классов**:
- Получение списка уроков
- Получение одного урока
- Создание урока
- Изменение урока
- Удаление урока

### Сериализаторы
Для работы контроллеров опишите простейшие **сериализаторы** на базе `ModelSerializer`.

### Тестирование
Проверяйте работу каждого эндпоинта с помощью **Postman**.

> **Примечание:** На данном этапе не заботимся о безопасности и не закрываем от редактирования объекты даже простой авторизацией.
